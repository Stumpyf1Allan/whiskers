Whiskers for Android: the same app as on Windows and Mac, built for one Android phone.

You don't need anything here for Windows or a Mac; their downloads are on the latest full release.

The phone app checks this page for its own updates (latest-android.json) and offers each new build itself. It is built and checked on an Android emulator by the Android workflow, and signed with the same key every time, so an update installs over the app already there and keeps its data.
